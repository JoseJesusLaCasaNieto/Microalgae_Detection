# PhD Research: Microalgae Detection in Photobioreactors

Welcome to the repository dedicated to documenting my PhD research workflow, progress, and academic resources. This project aligns with the ongoing research lines at the **University of Almería**, specifically focusing on the optimization and automation of microalgae detection within photobioreactors.

## 📌 Project Overview
The main goal of this PhD is to develop advanced methodologies for monitoring and detecting microalgae cultures. Photobioreactor environments require precise control and analysis, and this repository will host the codebase, datasets, and documentation generated throughout this academic journey.

Currently, the repository is in its initial setup phase, focusing on:
*   Initial documentation and PhD study plan.
*   State-of-the-art review and foundational research frameworks.
